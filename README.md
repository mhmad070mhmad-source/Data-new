# SAAD DATA — Spice Invoice Management

تطبيق عربي بواجهة خضراء وبيضاء لإدارة مخزون الشاحنة وفواتير المبيعات.

## المزايا
- لكل صنف سعر بيع وكمية في الشاحنة بوحدة بكت؛ كل بكت = 4 حبات.
- فاتورة باسم الماركت والتاريخ ورقم تلقائي وجدول: الصنف، الكمية بالبكت، سعر البكت، الإجمالي، والإجمالي النهائي.
- إرسال الفاتورة أو التقرير عبر واتساب.
- تقارير الأصناف الأكثر طلباً لكل ماركت والأكثر مبيعاً بين جميع الماركتات.
- تعديل الفواتير وحذفها مع تحديث المخزون.
- بيانات محلية مستقلة على كل جهاز. لا توجد مزامنة سحابية أو قاعدة مشتركة، لذلك لا تختلط بيانات الجهازين.
- تصدير واستيراد نسخة احتياطية JSON.
- زر الرجوع في أندرويد يرجع خطوة واحدة في التنقل، ثم إلى الرئيسية، ثم يخرج من التطبيق.

## بناء APK عبر GitHub
1. فك ضغط ملف ZIP.
2. أنشئ مستودعاً جديداً على https://github.com/
3. ارفع جميع محتويات المشروع، بما فيها مجلد `.github`.
4. افتح Actions وشغّل `Build Android APK`.
5. بعد نجاح البناء، نزّل Artifact `saad-spice-debug-apk` وفك ضغطه للحصول على `app-debug.apk`.

كل تثبيت يحتفظ ببياناته محلياً ولا يرسلها إلى الجهاز الآخر. لا تستورد نسخة احتياطية من الجهاز الآخر إذا أردت الحفاظ على استقلال البيانات.
